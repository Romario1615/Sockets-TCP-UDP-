Fundamento

TCP mantiene una conexión entre cada cliente y el servidor. Cada respuesta vuelve por el socket del cliente que envió el mensaje.

Código fuente de la práctica

Son los mismos programas que ejecuta el panel. Solo utilizan módulos incorporados de Node.js.

  
Realiza la práctica paso a paso
  1. Inicia el servidor de la modalidad elegida.
    Espera a que aparezca el estado «Escuchando».
  2. Conecta el cliente 1 y después el cliente 2.
    En el chat, indica primero el nombre de cada usuario.
  3. Escribe mensajes y revisa las tres consolas.
    TCP responde en mayúsculas; UDP cuenta palabras; el chat reenvía el mensaje a los demás usuarios.
  4. Escribe salir o pulsa Salir en un cliente.
    Comprueba que el servidor y el otro cliente siguen activos.
